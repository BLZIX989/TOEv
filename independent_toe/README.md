# independent_toe/ — Independent Theory Reconstruction Experiment

**This is an adversarial-independence branch, isolated from the canonical UOC/SEIT/ARBS/MDCL
closure program.** Its purpose is to determine whether the mathematical/physical content already
present in the TOEv corpus — read as raw mathematics, stripped of UOC's project-specific
terminology — is sufficient to reconstruct a unified physical theory *without assuming* that the
UOC architecture (DTC, Γ=κ∘τ∘Δ, any proposed persistence functional, spectral cutoff,
horizon-information law, particle-spectrum mapping, or universal functional) is correct.

## Governing rule

**The existing project corpus is DATA, not the theory.** Every object extracted here is labeled by
its actual mathematical content (operator, semigroup, projector, connection, functional, ...)
first; its UOC project name is recorded only as provenance metadata, never as a definition.

## Relationship to the rest of the repository

- **Read-only with respect to the canonical corpus.** `independent_toe/` reads
  `source_records/`, `registries/`, `compiler/dag/`, and the completed `derivations/C0/PRF-PRIM/`
  work as *inputs*, but never writes to them. No canonical file was modified by this branch.
- **Append-only within itself.** Every deliverable here is versioned by phase
  (`PHASE_0_REPORT.md`, and later `PHASE_1_REPORT.md`, etc.) — nothing is overwritten across phases.
- **Independent status ontology.** Findings here use DERIVED / CALCULATED / CONDITIONAL / ADMITTED
  / CANDIDATE / OPEN / FALSIFIED, evaluated purely against independently-recoverable mathematics —
  never against "does this match UOC."

## Status

**Phase 0 only.** Directory architecture, ontology-neutral object registry, independent source
index, mathematical-object dependency graph, candidate primitive registry, candidate common-kernel
registry, derivation ledger, workbook templates, and Master Independent-ToE DAG. **No physical
derivation has been attempted yet** — Phase 0 explicitly precedes Phase 1 ("reconstruct established
physics") through Phase 14 ("final theory object"), none of which have been executed.

See `PHASE_0_REPORT.md` for what was found, what recurs, and what the highest-leverage next
independent derivation is — a recommendation only, not yet executed.
