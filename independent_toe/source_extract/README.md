# source_extract/

- `ONTOLOGY_NEUTRAL_OBJECT_REGISTRY.xlsx` / `ontology_neutral_objects.csv` -- the Phase 0 core
  deliverable: 36 mathematically-defined objects extracted from the corpus, described by their
  actual mathematical content, not their UOC project label.
- `INDEPENDENT_SOURCE_INDEX.csv` -- independent-reconstruction-specific source metadata (which
  sources are mathematically dense vs. narrative/planning, how many objects were mined from each).
  This deliberately does NOT re-list the 149 (Phase 1) + 318 (Phase 1.5) raw worksheets
  individually -- those are already fully indexed in `source_records/inventory/SOURCE_INVENTORY.csv`
  and `registries/source_registry_vNEXT.csv`. This file adds only what those don't carry.
